# 会话分析

底部面板适合切换会话；编辑区的 **会话分析** 用来比较用量、找出耗时较长的会话，并查看某一轮发生了什么。

## 展示约定

分析页仅使用单行工具栏、数据栏和 13px 分区标题，禁止“大标题 + 描述”的页头。总览将会话表放在主区域、图表放在侧边；详情将用量、耗时与所选回合明细并排。Token、输入、输出、缓存命中、回合和耗时采用紧凑数据栏。

通过重新排布分区、减少空隙和行内呈现元数据提高密度，正文保持 12–13px；耗时图坐标使用独立的 12px HTML 标签，不随图形缩小。窄编辑区按可用宽度重新排列，保留全部字段和操作。

## 打开与查看

- 点击底部面板右上角的图表按钮，或执行 **Codex 会话：打开会话分析**。页面打开在当前编辑器组，不另开 VS Code 窗口；再次打开复用同一个标签。
- 总览默认包含当前工作区内的交互会话。搜索和工作目录筛选同时作用于数字、图表与列表；筛选独立于底部面板。
- 点击会话标题进入详情；底部会话行悬停时的图表按钮也可直接进入详情。普通点击会话仍然切换官方 Codex 侧栏。
- 在单会话页点击耗时柱，或点击表格中的回合序号。图表、选中行和右侧明细同步显示该轮；左右方向键移动，Enter / 空格选中。
- 耗时图每页 40 轮，表格每页 30 条，可查看全部已读取记录。新回合到达时不替换正在查看的回合；所选记录被移除时明确提示。
- “审阅本轮”打开底部面板的该轮审阅；“打开 Codex”切换官方侧栏。查看分析不自动标记已审阅。

## 数字的含义

**Token** 使用每条会话的最新累计快照。跨会话只累加有记录的值，并显示记录覆盖数；未知值显示 `—`，明确为零才显示 `0`。带分叉继承标记的会话仍在列表和详情中，但不加入跨会话 Token、轮次与耗时汇总。

**缓存命中率** 为有效记录的缓存输入总量除以输入总量，按输入量加权。只使用输入、缓存均存在且缓存不大于输入的记录；输入总量为零时比例显示 `—`。

**Token 环图** 只使用输入、输出均存在的记录，中心为两者之和。缓存字段完整时分成非缓存输入、缓存输入、输出三部分，互不重复；缓存缺失或不一致时仅显示输入、输出两部分。环图覆盖数可能与累计 Token 不同。推理输出属于输出，不再叠加；缓存写入和推理输出的原始值在详情下方显示。

**回合** 按回合 ID 去重。结果统计只列已完成、失败、已停止；总轮次还包含尚无结果的回合。缺少结果时在表格显示 `—`，不推断成正在运行。历史记录不足以确认完整计数时，总数保留 `—`。

**当前状态** 与回合结果分开。分析页收到明确的开始事件后，只有匹配该回合 ID 的一轮会显示运行中、待批准或待回复；旧轮不会跟着改变。完成、断线或观测中断后清除运行关联。回合结果和耗时仍由本地记录更新。

**审阅状态** 统一使用未审阅、待审阅、已审阅、需重审。首次读取的历史回合显示未审阅，不批量生成待审阅提醒。

**执行耗时** 只使用明确记录的 `duration_ms`。总览按已记录执行时长排列会话；详情的中位数、P95、最长值只包含已结束且有耗时的回合。P95 使用最近秩法。图中零耗时为实心短线，缺失耗时为空心标记，不用会话创建至今的时间填补。

**文件与操作** 来自所选回合记录的文件变更。文件数按完整路径去重；同一文件的多次操作分别计数，新增、修改、删除分开显示。没有文件记录不等于没有修改工作区；命令直接写文件可能不在这类记录中。补丁内容通过既有审阅入口按需打开，分析页只传文件摘要。

## 数据更新

分析页与底部面板共用本地记录读取器、文件监听及 15 秒检查。回到分析标签或点击刷新会触发读取；启用实时监听后，当前状态沿用该窗口已经观测到的事件。统计和逐轮耗时仍来自落盘记录。

工作区或 Codex 数据源变化时清除旧详情和筛选；旧读取结果不能覆盖新来源。隐藏的分析页不接收完整快照，重新可见时读取当前状态。页面只保存搜索、排序和当前查看位置等视图偏好，不保存新的聊天或补丁副本。

本版不展示费用、当前上下文占用、系统提示词／工具定义占比、逐请求耗时拆分或逐轮 Token；现有累计字段不足以可靠支持这些细分。
